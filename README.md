# AI Resume Analyzer

An NLP-based application that analyzes resumes, extracts skills, and matches them with job descriptions.

## Features

- Resume PDF upload
- Skill extraction
- Job description matching
- Match percentage calculation
- Missing skill recommendations

## Technologies

- Python
- NLP
- Scikit-learn
- NLTK
- Streamlit

## Status

Project under development.

## Future Scope

- Semantic matching using Transformers
- Resume ranking
- ATS score generation
- Personalized improvement suggestions
